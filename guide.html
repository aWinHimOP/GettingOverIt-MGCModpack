使用教程

Mod 怎么装、外置地图怎么放、Modpack 页面在哪 —— 都在这页。

游戏里的「Modpack 页面」到底在哪第一次进游戏最容易找不到的东西 怎么装 Mod两种方式：游戏内下载 / 手动放文件 外置地图怎么用下载的地图放哪、怎么开 文件路径速查Mods / Maps / 存档 / 日志

游戏里的「Modpack 页面」在哪

模组包没有独立的桌面图标，所有页面都在游戏内的暂停菜单里。

  1. 进游戏后点左上角的暂停键（两条竖线那个）。
  2. 菜单左边是一列页面：主页面 / 游戏设置 / Map(地图) / Mod(模组) / 社区/资源 / 设置 / 关于。
  3. 点 Mod(模组) —— 左边列出的就是已安装的模组包，点进去是它自己的设置页。
  4. 点 Mod 管理 —— 这里能看到所有已识别的模组包，并总开关（开 / 关）。

怎么装 Mod

模组包是一个 .modpack 文件（其实是个 zip），装 = 放到对的地方 + 启用。

方式一：游戏内下载（推荐）

  1. 暂停 → 社区/资源 → 「资源」页，找到想要的模组包。
  2. 点右边的下载，等它下完（会显示百分比）。
  3. 回到 Mod(模组) 页面，新的模组包已经出现在左边了。
  4. 点进去，用开关打开；有些 Mod 还需要重启游戏才生效。

方式二：手动放文件

从网盘或群里拿到 .modpack 文件后，丢进这个目录：

/sdcard/Android/data/com.noodlecake.gettingoverit/files/MGCModpack/Mods/

放好之后完全退出游戏再重进，然后在「Mod 管理」里点一下 刷新 Modpack 列表，它就会出现在列表里。

没有文件管理器能看到 Android/data 的话，用 MT管理器、ZArchiver 这类工具，安卓 11 以上还需要在授权弹窗里点「允许」。

外置地图怎么用

地图包是 .mappack 文件，和 Mod 一样是「放对位置 + 游戏里选」。

  1. 在 社区/资源 页下载地图包，或者从网盘拿。
  2. 手动安装的话，放进这个目录：
    /sdcard/Android/data/com.noodlecake.gettingoverit/files/MGCModpack/Maps/
  3. 重开游戏，暂停 → Map(地图) 页，列表里就能看到。
  4. 选中它，然后新游戏，就会从这张图的开头开始。

地图和原版进度互不影响，换回原版只要在同一个页面选回默认地图。

文件路径速查

全部在应用私有目录下，卸载 App 会一起删掉，换机前记得备份。

Android/data/com.noodlecake.gettingoverit/files/MGCModpack/
├─ Mods/            ← .modpack 模组包放这里
├─ Maps/            ← .mappack 地图包放这里
├─ 存档/            ← 「存档」Mod 的快照
├─ HotUpdate/       ← 热更下来的 DLL / 资源包 / 配置
└─ Logs/            ← 运行日志，出问题先看这里

游戏本体自己的存档不在这里，卸载游戏时系统会一起清掉 —— 想留进度请在游戏内正常退出。
