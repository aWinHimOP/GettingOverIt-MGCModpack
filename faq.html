常见问题

装 Mod、外置地图、页面在哪，还有各种转圈和闪退。

Modpack 的页面在哪？找不到入口

没有独立的 App 图标，所有功能都在游戏内：进游戏 → 点左上角暂停键 → 左边一列就是主页面 / 游戏设置 / Map(地图) / Mod(模组) / 社区/资源 / 设置 / 关于。

想看装了哪些模组包：点 Mod(模组)；想总开关某个包：点 Mod 管理。

怎么装 Mod？

推荐：暂停 → 社区/资源 → 找到模组包 → 点下载 → 回到「Mod(模组)」页面打开开关。

手动：把 .modpack 放进 MGCModpack/Mods/，完全退出游戏再重进，然后在「Mod 管理」里点刷新 Modpack 列表。

详细图文在 教程页。

外置地图怎么用？

地图包是 .mappack。游戏内可以在「社区/资源」直接下载；手动装就放进 MGCModpack/Maps/，重开游戏后在 Map(地图) 页选中它，再点新游戏。

装好的 Mod 没反应 / 列表里看不到

按顺序排查：① 文件是不是真的在 Mods/ 里（注意别放成 Mods/xxx/xxx.modpack 多套了一层）；② 有没有完全退出游戏再进（不是退到后台）；③ 在「Mod 管理」里点一次刷新 Modpack 列表；④ 有些 Mod 要在它自己的设置页里单独打开开关。

启动一直转圈 / 同步卡住

多半是网络。切换 WiFi / 流量重试一次；还是不行就去 下载页 拿网盘里的完整包。

资源页里的 Mod / 地图下载失败

客户端会自动换源重试。如果全部失败，说明更新服务器连不上，去网盘手动拿包，按上面的路径放好。

更新之后存档还在吗？

在。热更新只替换程序文件，不动玩家数据。但还是建议定期备份 MGCModpack 这个目录。

会不会被判定作弊？

这是单机游戏，没有联机也没有反作弊。但请自觉：用 Mod 跑出来的成绩别当成原版记录去发。

iOS 能用吗？

不能，只做了安卓。

怎么卸载干净？

卸载 App 会把 MGCModpack 目录一起删掉。只想关掉 Mod 的话，在「Mod 管理」里把总开关关掉即可，不用卸载。
