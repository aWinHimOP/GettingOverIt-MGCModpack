# GettingOverIt-MGCModpack

**Getting Over It（掘地求升）手机版的扩展模组包。**

这个仓库只做一件事：**当更新服务器**。游戏里的 `MGCLoader` 启动时会来这儿拉版本清单和配置，
所以这里只有清单、配置和编译好的产物，没有源码。

> **源码不在这里。** 本仓库是公开的发布端仓库，只包含下面这些文件。

## 仓库内容

这个仓库是**纯发布端**，由构建脚本自动推送，不含源代码。目录结构：

| 路径 | 说明 |
|---|---|
| `manifest.json` | 版本清单。客户端据此决定是否需要下载新的 `MGCModpack.dll`。`rev` 单调递增，变大即强制重下。 |
| `config.json` | 运营配置。改这个**不需要重新发布 DLL**，玩家下次启动游戏即可生效。 |
| `versions/<版本号>/MGCModpack.dll` | 各版本的模组包主程序。 |
| `versions/<版本号>/info.json` | 该版本的元信息（SHA256、体积、更新说明、发布时间）。 |
| `about-icon.png` | 关于页顶部图标。 |
| `panel-placeholder.png` | 主页面板图片的透明占位图（692×590），用于占住显示区域的比例。 |
| `bundle/*.unity3d` | UI 资源包（AssetBundle）。见下节。 |

### 客户端如何校验

`MGCModpack.dll` 下载前后都会比对 **SHA256**：

- 清单里的 `sha256` 是**唯一的信任根**。清单里缺 `sha256` 的版本会被客户端直接拒绝下载。
- 本地已有的版本若 SHA256 与清单一致，**跳过下载**，不浪费时间重复传输。

## 运营配置（config.json）

改完配置推送到本仓库，玩家**下次启动游戏**时加载器会拉取并缓存。
配置在游戏运行中改动**不会立即生效**（客户端只在启动时读一次）。

关于「换行」：文案字段里的换行要写成 `\n`（反斜杠 + n），
客户端的 JSON 解析器会自己把它转成真实换行。

## UI 资源包（bundle）

游戏的界面由三个 AssetBundle 组成：

| 资源包 | 内容 |
|---|---|
| `ui_mainmenu.unity3d` | 主菜单（含设置、地图、模组、关于等面板） |
| `ui_pause.unity3d` | 暂停键 |
| `ui_uicontrols.unity3d` | 通用 UI 控件 |

原先它们**只存在于 APK 内部**（`assets/AssetBundles/`），
意味着改动界面就必须让玩家重新打包并安装 APK。

现在客户端会优先从本地热更新目录读取资源包，找不到才回退到 APK 内置的那份：

```
<游戏数据目录>/MGCModpack/HotUpdate/bundle/<名字>.unity3d
```

启动时的流程是：

1. 读 `manifest.json` 里的 `bundles` 段；
2. 逐个资源包算本地文件的 SHA256；
3. **一致就跳过**，不一致（或本地没有）才从 `url` 下载；
4. 下载后写盘，启动时从该目录加载。

所以换一套 UI 只需要推送新的资源包 + 更新清单，**不用重发 APK**。

## 常见问题

**游戏打不开 / 卡在加载界面？**
先断网再启动。加载器在拉不到清单时会回退到本地已缓存的版本。

**模组没生效？**
确认游戏有网络权限，且设备能访问 `awinhimop.github.io`。

**想恢复原状？**
删掉游戏数据目录下的 `MGCModpack` 文件夹即可（注意这会一并清掉模组配置与头像等数据）。
